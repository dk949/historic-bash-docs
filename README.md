# Historic documentation for Bash

[![Deploy static content to Pages](https://github.com/dk949/historic-bash-docs/actions/workflows/deploy.yml/badge.svg)](https://github.com/dk949/historic-bash-docs/actions/workflows/deploy.yml)


This page hosts documentation for each version of bash from 2.0 to today. All
files have been pulled out of arrives provided by the GNU project with no
modifications.

## Building

```
npm i
npm run build
npm run preview
```

## (Re)fetching the docs

You can use the [scripts/fetch-all.sh](scripts/fetch-all.sh) script to download
and extract all/some of the documentation files.
